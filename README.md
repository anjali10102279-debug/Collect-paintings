# Collect paintings

A guess-the-Indian-artist game. Open `index.html` in a browser, or host the folder on GitHub Pages / any static host.

- `index.html`: the whole site (HTML, CSS and JS in one file)
- `images/`: the paintings used in the game. Keep this folder next to `index.html`.

The only external request is Google Fonts (Fredericka the Great, Cormorant Garamond).

## Images
Paintings are shown for recreation and representation only. They belong to their respective artists and rights holders. Check each work's copyright status before publishing the repository publicly.
